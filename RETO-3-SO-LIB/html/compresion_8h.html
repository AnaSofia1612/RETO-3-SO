Detailed Description

Módulo de compresión RLE con header y metadata binaria.

Define el formato del archivo binario comprimido:

┌──────────────────────────────────────────┐ │ FileHeader (16 bytes, packed) │ │ magic : 0x524C4543 ("RLEC") │ │ version : 1 │ │ num_bloques: cantidad de bloques │ │ size_total : bytes comprimidos totales │ ├──────────────────────────────────────────┤ │ Por cada bloque: │ │ BlockHeader (8 bytes, packed) │ │ bloque_id : índice del bloque │ │ size_bloque : bytes comprimidos │ │ Datos comprimidos (RLE: [cnt][char]) │ └──────────────────────────────────────────┘

Pipeline: char** bloques → comprimir_bloques() → unsigned char* payload unsigned char* payload → guardar_archivo() → file.bin file.bin → leer_archivo() → descomprimir_bloques() → char*
