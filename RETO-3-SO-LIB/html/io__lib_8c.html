Detailed Description

I/O con librería estándar de C.

Diferencia clave con io.c:

io.c (syscalls directas) io_lib.c (librería estándar) ───────────────────────────── ────────────────────────────── open() → fd del kernel fopen() → FILE* con buffer en heap write() → va directo al kernel fwrite() → acumula en buffer de libc mmap() → mapea en memoria fread() → copia desde buffer de libc close() → cierra fd fclose() → vacía buffer y cierra fd

La libc mantiene un buffer interno y solo llama a write() cuando ese buffer se llena o cuando se llama fclose()/fflush(). Eso puede reducir el número de syscalls, pero agrega una copia extra en memoria (heap → buffer libc → kernel).

Con archivos pequeños (< 8KB) fwrite() puede resultar en UNA sola syscall write() al hacer fclose(), mientras que io.c hace una por cada chunk de 4KB. Con archivos grandes, el comportamiento converge.
